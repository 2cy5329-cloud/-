# 전입/전출 자동 집계 웹 프로그램

## 무엇을 실행하면 되나요?
**`run.py` 하나만 실행**하면 됩니다.

```bash
python run.py
```

실행하면 콘솔에 접속 주소가 출력되고, 브라우저가 자동으로 열립니다.
기본 접속 주소: `http://127.0.0.1:8000`

> 이 프로그램은 **웹 UI가 있는 프로그램**입니다. 콘솔에 보이는 주소로 접속해서 사용합니다.

---

## 반응이 없는 것처럼 보일 때
아래는 정상 동작입니다.

- 실행 후 콘솔이 멈춰 있는 것처럼 보임 → **서버가 실행 중이라 정상**
- 아무 창이 안 뜸 → 브라우저에서 `http://127.0.0.1:8000` 직접 접속
- 포트 충돌 오류 발생 → 아래처럼 포트 변경

아래 로그가 보이면 정상입니다.

```text
[시작] 전입/전출 자동 집계 웹앱
[안내] 접속 주소: http://127.0.0.1:8000
[상태] 서버가 정상적으로 실행되었습니다.
```

윈도우에서 더블클릭 실행 시 창이 바로 닫히면, `cmd`(명령 프롬프트)에서 아래처럼 실행하세요.

```bash
python run.py
```

```bash
python run.py --port 8010
```

## 파일 역할 (헷갈리지 않게)
- `run.py` ✅ **사용자가 실행하는 파일(진입점)**
- `app.py` 내부 웹 화면/요청 처리
- `processor.py` 집계 계산 로직
- `xlsx_reader.py` 엑셀/CSV 읽기
- `tests/test_processor.py` 테스트 코드(실행 대상 아님)

즉, 실제 사용 시에는 **run.py만 실행**하면 됩니다.

## 기능
- 기준 지역 전입/전출 건수
- 이전지역 → 새지역 이동 흐름표
- 연령대별 전입/전출 현황

## 입력 파일 필수 컬럼
- 이름
- 생년월일
- 이전주소
- 새주소
- 이동구분 (전입/전출)
