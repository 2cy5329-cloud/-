# 전입/전출 자동 집계 도구

## 가장 쉬운 실행 방법 (권장)
이제는 **`index.html` 파일을 브라우저에서 바로 열면 됩니다.**

- Python 실행 불필요
- 서버 실행 불필요
- UI에서 파일 업로드 후 바로 집계

### 사용 방법
1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
2. 기준 지역/연도를 입력합니다.
3. `.xlsx` 또는 `.csv` 파일을 업로드하고 **자동 집계 실행**을 누릅니다.

> 필수 컬럼: `이름`, `생년월일`, `이전주소`, `새주소`, `이동구분(전입/전출)`

---

## 기존 Python 서버 방식 (선택)
기존 방식이 필요하면 아래로 실행할 수 있습니다.

```bash
python run.py
```

접속 주소: `http://127.0.0.1:8000`

---

## 기능
- 기준 지역 전입/전출 건수
- 이전지역 → 새지역 이동 흐름표
- 연령대별 전입/전출 현황
